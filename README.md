# GlobalMusic 🎵

Dünya genelinden müzik ve video keşif platformu.

## Özellikler

- 🎵 Müzik keşfi
- 🎬 Video keşfi
- 🔎 Hızlı arama
- ▶️ Müzik oynatıcı
- 📱 Mobil uyumlu tasarım
- 🌙 Karanlık / açık tema
- ⬇️ İzin verilen içeriklerde indirme
- 🌍 Ülke ve müzik türleri
- 🤖 Otomatik içerik keşif altyapısı
- 🗄️ Supabase veritabanı
- ⚡ Vercel Cron

## Teknolojiler

- Next.js
- React
- TypeScript
- Supabase
- Vercel

## Kurulum

```bash
npm install
npm run dev
